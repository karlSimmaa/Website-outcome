What is a computer?

A computer is an electronic machine that takes raw data as input, processes it using software instructions, and outputs a useful result. Its physical parts, called hardware, include the screen, keyboard, and an internal Central Processing Unit (CPU) that acts as the device's brain. Software programs tell this hardware exactly what to do, allowing the machine to store information, run applications, and perform complex tasks. Today, computers exist in many forms, from large office desktops to the smartphones in our pockets.

1957

John Backus leads the IBM team that releases FORTRAN, the first widely used high-level programming language, making computer programming accessible beyond scientists and mathematicians

1958

Jack Kilby & Robert Noyce independently invent the integrated circuit (microchip), packing multiple electronic components onto a single piece of semiconductor material to drastically reduce computer size

1968

Douglas Engelbart demonstrates "The Mother of All Demos," debuting the computer mouse, hypertext links, video conferencing, and word processing in a single live presentation

1969

US Department of Defense commissions ARPANET, the world's first operational packet-switching network and the foundational precursor to the modern global internet

1971

Federico Faggin, Ted Hoff & Masatoshi Shima design the Intel 4004, the world's first commercially available single-chip microprocessor, placing an entire CPU onto one tiny microchip

1975

Ed Roberts releases the Altair 8800, the first commercially successful personal computer kit, which inspired the founding of Microsoft and the microcomputer revolution

1977

Steve Jobs & Steve Wozniak launch the Apple II, one of the first highly successful, mass-produced consumer personal computers featuring color graphics and a built-in keyboard

1981

IBM introduces the IBM PC (Model 5150), which standardises personal computer hardware and software architecture and legitimises the PC for global business use

1984

Apple releases the Macintosh, popularising the Graphical User Interface (GUI) and the mouse for everyday consumers through a highly successful commercial campaign

1991

CERN releases the World Wide Web to the public, popularising the use of web browsers and interconnected text links for everyday internet users and creating the framework for the modern digital era.

1998

Google introduces its search engine, standardising how information is indexed on the internet and legitimising the web as a hyper-efficient tool for global knowledge retrieval.
